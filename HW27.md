### **What are components?**

Components are the basic building blocks of an Angular application. 

Every part of the user interface is usually represented by a component, such as a navigation bar, login page, employee table, or search form. 

Each component is independent and reusable, making large applications easier to organize and maintain.

**A component typically contains a TypeScript class for business logic, an HTML template for the user interface, and a CSS or SCSS file for styling. Angular combines these parts into a single reusable unit.**

### **What are directives?**

**Directives are special instructions that tell Angular how to modify the behavior or appearance of HTML elements.** 

They allow developers to add dynamic functionality without writing manual DOM manipulation code.

**Angular provides several built-in directives, such as `*ngIf` for conditional rendering, `*ngFor` for looping through collections, and `ngClass` for dynamically applying CSS classes.** 

Developers can also create custom directives when needed.

### **What are the differences between Component and Directive?**

**A component is a special type of directive that always has its own HTML template and is responsible for displaying part of the user interface.** 

**Components define both the structure and behavior of a section of the application.**

**A regular directive does not have its own template. Instead, it changes the behavior or appearance of existing HTML elements. In other words, every component is a directive, but not every directive is a component.**

### **What is a module?**

**A module is a container that groups related Angular features together.** 

It organizes components, directives, pipes, and services into logical units so Angular knows how different parts of the application are connected.

The root module is usually `AppModule`, which starts the application. 

Large enterprise applications often contain multiple feature modules to improve organization, maintainability, and lazy loading.

### **What is Angular CLI?**

**Angular CLI is the official command-line tool for Angular development.** 

It automates many common development tasks so developers can focus on writing application logic instead of configuration.

Angular CLI can create new projects, generate components, services, modules, and other files. 

It can also build the application, start a development server, run tests, and prepare the application for production deployment.

### **What is a service?**

**A service is a class that contains reusable business logic or shared functionality.** 

Instead of placing all logic inside components, Angular encourages developers to move common logic into services.

Services are commonly used for calling REST APIs, handling authentication, processing data, sharing information between components, and implementing business rules. 

This keeps components smaller and easier to maintain.

### **What is dependency injection in Angular?**

Dependency Injection, or DI, is a design pattern where Angular automatically creates and provides objects instead of letting classes create them directly.

For example, a component can request an employee service, and Angular injects the service automatically. This reduces coupling between classes, improves code reuse, and makes unit testing easier because mock services can replace real implementations.

### **What is data binding?**

**Data binding is the mechanism that connects the component data with the HTML template. It allows data to flow between the application logic and the user interface automatically.**

Instead of manually updating HTML elements with JavaScript, Angular keeps the data and the view synchronized. This reduces boilerplate code and makes applications easier to develop and maintain.

### **How do you categorize data binding types?**

**Angular supports four main types of data binding.**

Interpolation displays component data inside HTML using double curly braces.

Property binding sends data from the component to an HTML element property.

Event binding sends user actions, such as button clicks, from the HTML template back to the component.

Two-way data binding combines property binding and event binding so both the component and the user interface stay synchronized automatically.

### **What is interpolation?**

Interpolation is a one-way data binding technique used to display component data in the HTML template. It uses double curly braces to evaluate expressions and display their values.

Whenever the component data changes, Angular automatically updates the displayed content. Interpolation is commonly used for showing text such as usernames, titles, prices, or employee information.

### **What is ngIf directive?**

- `ngIf` is a structural directive that conditionally adds or removes HTML elements from the page. If the specified condition is true, Angular displays the element. If the condition is false, Angular removes the element completely from the DOM.

This directive is commonly used to display login messages, loading indicators, error messages, or different content based on user permissions.

### **What is *ngFor directive?**

- `ngFor` is a structural directive used to repeat an HTML element for every item in a collection.

It is commonly used to display lists such as employees, products, orders, or search results. Angular automatically creates one HTML element for each object in the collection, making list rendering simple and efficient.

### **What is HttpClient and its benefits?**

**HttpClient is Angular’s built-in service for sending HTTP requests to backend applications. It supports common operations such as GET, POST, PUT, DELETE, and PATCH.**

HttpClient automatically converts JSON data into JavaScript objects, integrates with RxJS Observables, supports interceptors, and provides strong TypeScript typing. These features simplify communication between Angular and REST APIs.

### **What is RxJS?**

**RxJS is a library for reactive programming based on Observables. It allows developers to work with asynchronous data streams in a flexible and consistent way.**

Angular uses RxJS extensively for HTTP requests, user events, routing, and many asynchronous operations. RxJS also provides powerful operators that can filter, transform, combine, and process data streams.

### **What is an observable?**

**An Observable is an object that produces data over time. Unlike a normal variable, an Observable can emit multiple values asynchronously.**

Observables are commonly used for HTTP responses, user interactions, timers, and WebSocket communication. They allow applications to react whenever new data becomes available.

### **What is subscribing?**

**Subscribing means registering a listener for an Observable. An Observable does not begin producing data until something subscribes to it.**

When a subscription is created, Angular executes the asynchronous operation and delivers emitted values, errors, or completion events to the subscriber for processing.

### **What is the difference between promise and observable?**

A Promise produces only one result and finishes after the operation completes. Once resolved or rejected, it cannot emit additional values.

An Observable can produce multiple values over time and supports cancellation, lazy execution, and many transformation operators. Because of these capabilities, Angular primarily uses Observables for HTTP requests and other asynchronous tasks.

### **What is Angular Router?**

Angular Router is the built-in navigation system for Angular applications. It maps URLs to components and controls which component should be displayed when users navigate through the application.

It enables Single Page Applications to provide multiple pages without reloading the browser. Angular Router also supports route parameters, nested routes, lazy loading, and route guards.

### **What is router outlet?**

`router-outlet` is a placeholder in an Angular template where the routed component is displayed.

When users navigate to different URLs, Angular replaces the content inside the router outlet with the corresponding component while keeping the rest of the page unchanged.

### **What are router links?**

Router links are directives used to navigate between routes inside an Angular application.

Instead of reloading the browser like a normal HTML hyperlink, router links tell Angular Router to switch components dynamically, providing faster navigation and a smoother user experience.

### **What is Single Page Application (SPA)?**

**A Single Page Application loads the application only once when the browser starts. After that, navigation happens by updating the displayed content instead of loading entirely new web pages.**

Compared with traditional multi-page applications, SPAs usually provide faster navigation, better responsiveness, and a smoother user experience because most interactions happen inside the browser.

### **What is ngOnInit?**

`ngOnInit` is one of Angular’s lifecycle hooks. It is executed after Angular creates the component and initializes its input properties.

Developers commonly use `ngOnInit` to load initial data, call backend APIs, initialize variables, or perform setup tasks that should happen once when the component starts.

### **What is the difference between constructor and ngOnInit?**

The constructor is part of the TypeScript class and is called when Angular creates the component object. It is mainly used for dependency injection and simple object initialization.

`ngOnInit` is an Angular lifecycle hook that runs after the component has been fully initialized. It is the preferred place for loading data, calling services, and performing initialization that depends on Angular’s component lifecycle.

### **What are lifecycle hooks?**

**Lifecycle hooks are special methods that Angular calls automatically at different stages of a component’s life.**

They allow developers to execute code when a component is created, initialized, updated, checked, or destroyed. Common lifecycle hooks include `ngOnInit`, `ngOnChanges`, `ngAfterViewInit`, and `ngOnDestroy`.

### **What is metadata?**

**Metadata is additional information that tells Angular how a class should behave.** 

**Angular stores this information using decorators such as `@Component`, `@Injectable`, and `@NgModule`.**

For example, the `@Component` decorator specifies the component selector, template file, style files, and other configuration so Angular knows how to create and display the component.

### **What is template?**

A template is the HTML view associated with an Angular component. It defines what users see on the screen and how the component’s data is displayed.

Templates support Angular features such as interpolation, property binding, event binding, directives, and pipes, making the user interface dynamic and interactive.

### **What are pipes?**

Pipes are Angular features used to transform displayed data without changing the underlying data itself.

Common built-in pipes can format dates, currencies, percentages, numbers, uppercase text, and lowercase text. Developers can also create custom pipes to perform application-specific formatting.

### **What are attribute directives?**

Attribute directives modify the appearance or behavior of existing HTML elements without changing the page structure.

Examples include `ngClass`, which dynamically adds or removes CSS classes, and `ngStyle`, which changes element styles based on component data. These directives make user interfaces more flexible and responsive.

### **What are structural directives?**

Structural directives change the structure of the HTML document by adding, removing, or repeating elements.

The two most common structural directives are `*ngIf`, which conditionally displays elements, and `*ngFor`, which repeats elements for each item in a collection. These directives are essential for building dynamic Angular applications.
