### **What is HTML and what is its main responsibility in a web page?**

HTML stands for HyperText Markup Language. 

It is the standard markup language used to create the structure of a web page. 

**Its main responsibility is to define the content and organize elements such as headings, paragraphs, images, links, forms, and tables.** 

HTML tells the browser what each piece of content represents, but it does not mainly control visual design or complex behavior.

### **What is an HTML file essentially made of?**

**An HTML file is mainly made of HTML elements. These elements are written using tags, content, and sometimes attributes.** 

**The elements are usually organized in a tree-like structure,** with some elements placed inside other elements. For example, a paragraph element may contain text, while a link element may be placed inside the paragraph.

### **What does `<!DOCTYPE html>` do and why is it required?**

**`<!DOCTYPE html>` tells the browser that the document uses modern HTML5 standards.** 

It helps the browser render the page in standards mode. 

**Without it, the browser may enter quirks mode and use older rendering behavior.** 

This can cause inconsistent layouts and unexpected CSS results across different browsers.

### **What is an HTML tag and how does it work?**

**An HTML tag is a special keyword surrounded by angle brackets. It tells the browser what type of element should be created.** 

**Most HTML elements have an opening tag and a closing tag, such as `<p>` and `</p>`. The content is placed between them.** Some elements, such as `<img>`, do not wrap content and are known as void elements.

### **What is the difference between the `<head>` and `<body>` sections?**

**The `<head>` section contains information about the web page that is usually not displayed directly on the page.** It may include the page title, metadata, CSS links, JavaScript files, and character encoding. 

The `<body>` section contains the visible content that users interact with, such as text, buttons, images, forms, and navigation menus.

### **What is an HTML attribute and why is it needed?**

**An HTML attribute provides additional information about an element. Attributes are written inside the opening tag and usually use a name-and-value format.** 

For example, the `href` attribute tells a link where to go, and the `src` attribute tells an image where its file is located. Attributes are needed to configure elements and control their behavior.

### **How does the browser parse HTML and convert it into the DOM?**

**The browser reads the HTML file from top to bottom. It identifies tags, attributes, text, and relationships between elements.** 

It then creates an object for each HTML element and organizes these objects into a tree structure called the Document Object Model, or DOM. JavaScript can later use the DOM to find, modify, add, or remove elements.

### **What is CSS and what problem does it solve?**

**CSS stands for Cascading Style Sheets. It is used to control the visual appearance and layout of HTML elements.** 

**CSS solves the problem of separating page structure from page design.** 

**HTML defines what the content is,** while CSS controls colors, fonts, spacing, alignment, size, positioning, and responsive layouts.

### **Why is CSS not considered a programming language?**

**CSS is not usually considered a programming language because it does not contain general programming logic such as loops, functions, variables with complex behavior, or conditional execution in the traditional sense.** 

CSS is a style sheet language. It describes how HTML elements should look rather than giving the computer a sequence of instructions to execute.

### **What are the three ways to apply CSS to an HTML page?**

CSS can be applied using inline CSS, internal CSS, or external CSS. 

Inline CSS is written directly inside an HTML element using the `style` attribute. 

Internal CSS is written inside a `<style>` element in the `<head>` section. 

External CSS is written in a separate `.css` file and connected to the HTML page using a `<link>` element.

### **Why are inline styles generally not recommended?**

**Inline styles are generally not recommended because they mix page structure with visual design.** 

They also make the code harder to maintain and reuse. 

If many elements use inline styles, every element may need to be changed separately. External CSS is usually better because one style rule can control many elements across multiple pages.

### **What is the difference between `id` selectors and class selectors in CSS?**

**An `id` selector is used to target one specific element and is written with a `#` symbol.** 

**An HTML `id` should normally be unique on the page.** 

A class selector is written with a `.` symbol and can be used on many elements. Classes are better for reusable styles, while IDs are usually used for unique elements or specific JavaScript references.

### **What is the difference between margin and padding?**

Margin is the space outside an element’s border. It creates distance between the element and nearby elements. 

Padding is the space inside the border, between the content and the border. Both affect spacing, but margin controls external spacing, while padding controls internal spacing.

### **What is the difference between `position: relative` and `position: absolute`?**

**An element with `position: relative` remains in its normal position in the document flow.** 

It can then be moved slightly using properties such as `top`, `left`, `right`, or `bottom`. Its original space is still reserved.

**An element with `position: absolute` is removed from the normal document flow.** 

It is positioned relative to the nearest ancestor that has a position value other than `static`. If no such ancestor exists, it is usually positioned relative to the page.

### **What is JavaScript used for in a web application?**

**JavaScript is used to add behavior and interactivity to a web application.** 

It can respond to user actions, validate forms, update page content, send requests to a backend server, display messages, and control animations. 

**HTML provides the structure, CSS provides the design, and JavaScript controls dynamic behavior.**

### **What are the two ways to include JavaScript in an HTML file?**

**JavaScript can be included directly inside the HTML file using a `<script>` element. This is called internal JavaScript.** 

It can also be written in a separate `.js` file and connected using the `src` attribute of the `<script>` element. **External JavaScript is usually preferred because it improves organization and reusability.**

### **What is a variable in JavaScript and what types of values can it store?**

A variable is a named container used to store data. 

In JavaScript, variables can be declared using `let`, `const`, or the older `var` keyword. 

A variable can store strings, numbers, booleans, objects, arrays, functions, `null`, `undefined`, and other values. 

JavaScript is dynamically typed, **so the value type is determined at runtime.**

### **How does JavaScript interact with HTML elements through the DOM?**

**JavaScript uses DOM methods to find and control HTML elements.** 

**For example, it can use `document.getElementById()` or `document.querySelector()` to select an element.** 

After selecting it, JavaScript can change its text, style, attributes, or content. It can also create new elements or remove existing elements from the page.

### **What are loops used for in JavaScript, and can you give an example use case?**

**Loops are used to repeat a block of code multiple times.** 

They are useful when working with arrays, lists, or repeated operations. 

For example, a loop can go through a list of products and create an HTML element for each product. Common JavaScript loops include `for`, `while`, `for...of`, and array methods such as `forEach()`.

### **What is an event listener and why is it important in front-end development?**

**An event listener is a function that waits for a specific event to happen on an HTML element.** 

Common events include clicks, keyboard input, form submission, mouse movement, and page loading. 

Event listeners are important because they allow the web page to respond to user actions.

 **Without them, the page would remain mostly static and could not provide interactive behavior.**
